# FR-005-008 FACapture: FA Capture & Display of Portfolio Analytics Plan

**Related:** BR-005 Portfolio Analytics, FR-005-001..007

## Description
The FrontAccounting module lets an advisor open a client's Portfolio Analytics plan, run the `Ksfraser\Portfolio` engines, and display results inline.

## Primary actor
Advisor.

## Main flow
1. Advisor opens Portfolio Analytics Planning from the client menu. 2. System loads plan and runs engines. 3. Results persist against the client record.

## Postconditions
Portfolio Analytics plan results visible and stored for the client.
